How it works

From a description to a shortlist, in four steps

Each step narrows the search — from a rough description of your need down to a side-by-side comparison you can act on.

01

Describe your need

Search a condition directly, or describe it in plain language and let the AI assistant suggest a specialty.

02

Set your preferences

Narrow by city, budget, distance and whether reported outcome data is required.

03

Compare hospitals

Select up to three hospitals and see cost, distance, specialization and outcome data side by side.

04

Explore hospital details

Open a full profile — doctors, facilities, contact details and directions — before you decide.

About this build

A hackathon MVP, built to be extended

Vitality's frontend runs entirely on labelled demo data. Every screen is wired through a single API layer (js/api.js), so a backend team can connect real hospital records without reworking the interface.
